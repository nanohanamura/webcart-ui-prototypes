# さくらWebカート隔離試作 実装計画

**目的:** 本番と分離したさくらステージングURLで、現行商品データを使う操作可能な購入フローを店長が確認できるようにする。

**構成:** 試作08を新しい`09-sakura-staging/`へ複製せず、必要な責務ごとに静的画面、商品スナップショット、ブラウザ状態、検証スクリプトを分離する。商品スナップショット生成時だけ商品表・分類表を固定SELECTで読む。公開物はDBへ接続しない。

## 作成・変更する主な場所

- `09-sakura-staging/index.html`: 画面入口
- `09-sakura-staging/assets/styles.css`: 共通UI
- `09-sakura-staging/assets/app.js`: 商品表示・検索・カート・購入フロー
- `09-sakura-staging/data/catalog.json`: 検証済み商品スナップショット
- `09-sakura-staging/data/catalog-meta.json`: 件数・取得日時・検証情報
- `09-sakura-staging/scripts/remote_export.py`: サーバー上で標準出力へ商品JSONを出す固定SELECT処理
- `09-sakura-staging/scripts/build_snapshot.py`: SSH出力を検証し公開JSONへ変換
- `09-sakura-staging/scripts/deploy_staging.sh`: 固定配置先だけを扱うdry-run/execute配置
- `09-sakura-staging/tests/`: データ、画面、非接続、配置物のテスト
- `09-sakura-staging/manager-review.html`: 店長確認表
- `09-sakura-staging/README.md`: 更新、検証、復元手順
