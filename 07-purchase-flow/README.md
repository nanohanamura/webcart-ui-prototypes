# 菜の花村Webカート 購入フロー比較試作

`06-kitano.html` の商品一覧を入口に、商品選択から模擬注文完了までを操作できる静的プロトタイプです。

## 購入フロー

```text
商品一覧
→ カート
→ 利用状況の確認
→ Web会員ログイン
→ 登録済みのお届け情報
→ 注文内容の確認
→ 模擬注文完了
```

「配達を利用中でWeb注文は初めての方」と「新しく配達を希望する方」は電話相談へ案内し、注文完了には進みません。

## 現行Webカートとの対応

| 試作上の要素 | 将来維持する現行契約 |
|---|---|
| カテゴリー選択 | `gc_cd` |
| 商品検索 | `word` |
| 商品カード | 商品コード、商品名、規格、価格、温度帯 |
| カート | 商品ごとのフォーム、hidden値、PHPセッション、カート投入先 |
| ログイン | メールアドレスまたはWeb会員番号、暗証番号 |
| お届け情報 | Web会員情報、住所、電話番号、配達区分 |
| 注文確認 | 商品コード、数量、価格、注文者、お届け先 |

## NILEとの境界

この試作はNILEへ接続しません。`Chumonsha.csv`、`ChumonList.csv`、CSV列順・文字コード、NILE商品CD変換、顧客マスタ、注文入力、帳票、配達曜日コードは変更しません。

## データ

- カテゴリー：公開画面の調査用スナップショット53件
- 商品：公開画面の調査用スナップショット12件
- 会員情報：プロトタイプ専用の架空データ
- カート状態：ブラウザのローカル保存だけを使用
- 外部送信：なし
