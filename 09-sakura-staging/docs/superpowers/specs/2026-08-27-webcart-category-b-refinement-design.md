# B案 カテゴリー再編・表示調整 設計（2026-08-30確定）

## 目的

B案を、スマートフォンで大分類を選んだ際に小カテゴリーが1画面前後へ収まり、商品の種類を利用者が直感的に理解できる構成へ改善する。

   - 果菜・葉もの
   - 果物
   - きのこ
2. 肉・魚・卵・冷蔵冷凍品
   - 肉・魚
   - 卵
   - 豆腐・納豆
   - 乳製品
   - 漬物・こんにゃく
   - 冷蔵・冷凍食品
3. 調味料
   - 味噌
   - 醤油・つゆ・だし
   - 酢・みりん
   - 塩・砂糖
   - 油・マヨネーズ
   - ソース・カレー・香辛料
4. 米・パン・麺
   - 米
   - パン

商品がない小カテゴリーは表示しない。分類99は従来どおり非表示とする。

## 分類31の扱い

現行の分類31「味噌・要冷蔵品」には、味噌、冷蔵品、冷凍品が混在している。試作では現在の商品コードを基準に次のように分ける。

- 味噌: 1560、2458
- 冷蔵・冷凍食品: 647、1632、2299、2551、2552、2762、2842、2950、3170

これはB案の表示だけの振り分けであり、商品分類コード、管理画面、商品DB、NILE、CSVは変更しない。今後、分類31へ新しい商品が追加された場合は、表示側の振り分け追加が必要になる。

## 小カテゴリーボタン

- 商品数を表示しない。
- 2列を維持する。
- 文字は中央揃え、15px、太字とする。
- 縦の余白を縮め、見た目を約10%薄くする。
- 誤タップ防止のため、操作領域は44px以上を維持する。
- 長いカテゴリー名は省略せず折り返す。

## 変更範囲

B案だけを変更する。A案、C案、商品データ、購入フロー、外部公開は変更しない。
